# 08 话术

规则：短句，一句一行，不写开场问候段，不写落款。`{...}` 是你现场填的位置。**RM 数字一律从当期价目表填，手册不预设。** 不加倒计时，不加「最后机会」。

---

## A. 线上询盘第一次回复（中文）

```
Hi {称呼}
Bodaiju 在 Medini，日本发展商 Creed
一房 463 尺，两房 753 尺，三房 893 尺
外国人可以买，Medini 这区没有 RM100 万门槛
你是自己住还是投资？我按你的情况发资料给你
```

```

## D. 看房后跟进

看房后 24 小时内发。内容按当天实际情况写，不要套模板。生成方式：把当天笔记丢给 `viewing-follow-up` skill，它会输出买家版、业主版和看房记录三份。

骨架：

```
Hi {称呼}
昨天你说{他喜欢的那一点}
{承诺要给的东西}我附上了
{一个异议的回应，一句}
你要不要我再算一版{他关心的数字}给你？
```

只答一个异议。不要在这一条里放第二个。

## D-EN

```
Hi {name}
You mentioned {the thing they liked} yesterday
Here is {the item you promised}
{one-line answer to one objection}
Want me to run the {number they care about} again for you?
```

## E. 成本异议之后

```
Hi {称呼}
你问的总成本我列出来了
头期 {金额}
印花税 8% {金额}
同意费 {金额}，这笔我跟律师确认过了
合计大概 {金额}
要不要我按{户型}再算一版？
```

同意费未确认之前，这条不要发。

## F. 沉默客户唤醒

两周：
```
Hi {称呼}
{户型}这边{实际变化：剩几间/价目表更新/工程进度}
你那边还在考虑吗？没有的话我就不打扰你了
```

两个月：
```
Hi {称呼}
工程进度：{一句实况}
政策这边{有/没有}变化
你如果还在看柔佛，我随时可以更新给你
```

## F-EN

```
Hi {name}
{factual update: units left, new price list, construction progress}
Still looking at Johor? Happy to send an update
```

## G. 新价目表或新配套到手

```

## 写话术时的禁用清单

不要用：保证、稳赚、包租、最后机会、错过不再有、稀缺、不容错过。
不要用破折号。不要连续三个排比。不要写总结句。
中文不要用：不得不说、值得一提的是、总的来说、让我们一起。
英文不要用：nestled、boasts、vibrant、unlock、elevate、game-changer、look no further。
