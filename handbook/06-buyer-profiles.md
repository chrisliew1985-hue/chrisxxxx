# 06 客群与匹配

六类客群，各自问的问题不一样。第一次对话的目标是分辨他是哪一类，然后只讲他那一类关心的事。

## 1. 新加坡跨境通勤上班族

- **要的是**：总价低、过关方便、可以自住
- **匹配**：Type A 463 sf、Type B 753 sf
- **先问**：你从新加坡哪一区进出？平常走第二通道还是长堤？
- **必须讲**：RTS 站在 JB 市区不在 Medini（[05-location.md](05-location.md)）；CPF 不能用；2027–2028 才交楼，现在买不是现在住
- **风险**：他常常把「9 公里」理解成「20 分钟到公司」。用实测车程表拉回现实

## 2. 新加坡小额投资客

- **要的是**：入场门槛、租金回报、退出容易不容易
- **匹配**：Type A、Type B
- **先问**：你要的是现金流还是增值？预算里有没有算 8% 印花税和同意费？
- **必须讲**：[03-costs-taxes.md](03-costs-taxes.md) 的负现金流模型；RPGT 外籍 5 年内 30%、之后 10% 不归零；非居民租金税 30%
- **风险**：这类客户最容易被别人用「保证回报」抢走，也最容易在两年后回来骂人。宁可现在讲难听的

## 3. EduCity 家长（本地与外籍）

- **要的是**：离学校近、3 房、安全、有设施
- **匹配**：Type C 893 sf、Type C1 Dual Key
- **先问**：孩子读哪一所？几年级？打算住几年？
- **必须讲**：交付时间对不对得上孩子的学程；2027–2028 交付意味着现在还要租两年
- **风险**：交付时间是这类客户的硬约束，不要含糊

## 4. 本地（柔佛 / 吉隆坡）升级客

- **要的是**：产品力、发展商背景、二手转售
- **匹配**：Type C、Type C1
- **先问**：你现在住哪一区？这次是自住还是给家人？
- **必须讲**：leasehold 99 年与 freehold 的差别；服务式公寓的水电与门牌税可能按商业计
- **风险**：本地客对 Medini 的既往供应量有印象，直接把 [11-risks.md](11-risks.md) 摊开讲

## 5. 外籍 expat / 日韩买家

- **要的是**：发展商信誉、管理素质、生活圈
- **匹配**：Type B、Type C
- **先问**：你在马来西亚工作还是投资？打算持有多久？
- **必须讲**：Creed 的背景（[01-facts.md](01-facts.md)）；买房不等于签证
- **风险**：日资背景是最容易被过度承诺的地方。可以讲「日本发展商」，不要讲「日本品质保证」

## 6. 半自住半出租 / 两代同住

- **要的是**：Dual key 的灵活性
- **匹配**：Type C1 1,012 sf
- **先问**：两边分别给谁住？出租那一半打算长租还是短租？
- **必须讲**：短租受管理机构附则约束，交付后才定（[04-rules-eligibility.md](04-rules-eligibility.md)）；双匙单位转售客群较窄
- **风险**：不要把 dual key 说成「租一半就能供一间」，先用 [03-costs-taxes.md](03-costs-taxes.md) 的模型算给他看

## 分辨话术（第一次对话，三个问题）

```
1. 这间是自己住，还是投资？
2. 预算大概在哪个范围，是全现金还是要贷款？
3. 你打算什么时候要用到这间房？
```

第三个问题最关键。答案是「明年」的客户，这个项目对不上，早点讲清楚，省双方时间。
