# Tabs

A set of layered sections of content, displayed one at a time. Port of shadcn/ui `tabs` (new-york-v4).

## Props
`Tabs`: `value`, `defaultValue`, `onValueChange`. `TabsTrigger`/`TabsContent`: `value`.

## Usage
List on `muted` with `radius-lg`; active trigger on `background` with `shadow-sm`.
