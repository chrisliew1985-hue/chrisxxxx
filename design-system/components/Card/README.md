# Card

Displays a card with header, content, and footer. Port of shadcn/ui `card` (new-york-v4).

## Parts
`Card` › `CardHeader` (`CardTitle`, `CardDescription`) › `CardContent` › `CardFooter`.

## Usage
- Padding `space-6` (24px), gap 24px, radius `radius-xl`, `shadow-sm`, 1px `border`.
- Footer holds the actions, primary on the right.
