# Input

Displays a form input field. Port of shadcn/ui `input` (new-york-v4).

## Props
All native `<input>` props. Set `aria-invalid` to show the error state.

## Usage
- Always pair with a `Label` (`htmlFor`).
- Height `control-md` (36px), border `input`, focus ring `ring` at 3px/50%.
- Put helper and error text below in `muted` style / `destructive` color.
