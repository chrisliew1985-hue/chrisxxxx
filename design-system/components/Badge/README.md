# Badge

Displays a badge or a component that looks like a badge. Port of shadcn/ui `badge` (new-york-v4).

## Props
- `variant`: `default` · `secondary` · `outline` · `destructive`

## Usage
- Short status or count labels (1–2 words). Not clickable unless wrapped in a link.
- Fully rounded (`radius-full`), caption type (12px/500).
