## 一、房子分析（给你自己心里有数，别照念）

**算出来的数字**

| 项目 | 数字 |
| --- | --- |
| 建筑面积单价 | RM1,980,000 ÷ 3,144 sqft ≈ **RM630 / sqft** |
| 土地面积 | 35' × 80' = **2,800 sqft** |
| 土地单价 | ≈ **RM707 / sqft 地** |
| 平面图尺寸 | 单间宽 7,620mm（25尺）· 深 24,384mm（80尺）|

**平面图看到的真实卖点**（这些是图上确认有的，讲了不会错）

1. **楼下客房 + 独立浴室（bath 4）** — 长辈上不了楼、家佣、客人留宿，都解决。这是很多双层排屋没有的。
2. **干厨 + 湿厨分开，还有独立 laundry room** — 华人炒菜油烟不进屋，洗衣有自己的空间。
3. **5 个浴室配 4+1 房** — 主卧、房2、房3 各自带浴室，楼下客房一个，再加一个 powder room 给客人。几乎房房有厕所。
4. **楼上还有 family area + study area** — 不是只有房间，是多两个实用空间。3,144 尺是真的用得到。
5. **主卧带独立主浴 + 冷气台**，房2 带阳台。
6. **双车位车棚 + 侧边草地 + terrace** — Cluster 的好处：有独立屋的间隔感，价格低过半独立式。

**产品定位**

- **永久地契 + 非土著** — 将来转手买家群不受限制，这一点直接影响脱手速度。
- **全新空屋（bare unit）** — 买家可以照自己喜欢的风格装，不用先花钱拆掉别人的旧装修。
- **Gated & guarded** — Horizon Hills 是新山已经成熟的保安社区，不是刚开发的新区。

**目标买家**（决定你广告投给谁）

- 三代同堂的本地家庭 — 卖点是楼下客房 + 5 浴室
- 新加坡工作的家庭 — 卖点是永久地契 + 成熟保安社区
- 想从公寓 upgrade 的年轻家庭 — 卖点是 RM630/尺 拿到 3,144 尺 + 自家花园
