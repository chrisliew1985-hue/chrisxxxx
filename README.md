# Chris-Brain

Private knowledge vault for JB property content and marketing.
Serves as persistent memory for Claude Code across sessions.

**Start here:** [[CLAUDE]] holds the operating instructions — read it first
every session. [[home]] is the map of content.

## Structure
- `CLAUDE.md` — vault instructions and session commands
- `home.md` — index / map of content
- `areas/` — the two business tracks (residential, industrial)
- `reference/` — evergreen facts and reusable content blocks
- `logs/` — dated session logs (`YYYY-MM-DD-topic.md`)

## Conventions
- Wikilinks only: `[[note-name]]`
- kebab-case filenames
- One idea per note, linked generously
- Frontmatter on every note: `title, tags, created, updated`
