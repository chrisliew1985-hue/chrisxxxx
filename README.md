### 网页版 `web/`

`web/index.html` 是手机版速查页的源码。已发布：**https://claude.ai/artifact/CcpqfVZyHNAQ2Y1xqtvsj9**

网页版比 markdown 多三样东西：外籍买家成本试算器（改房价、成数、利率、同意费口径，现场算入场现金与月净现金流）、异议关键词筛选、待核实清单的勾选记录（只存在你自己的手机上）。

链接目前是私有的，要发给同事的话在页面右上角 Share 里开权限。改了 `web/index.html` 之后，重新发布同一个文件就会更新这个链接，网址不变。

## 三条使用纪律

1. **报价前先看 [12-verify-list.md](handbook/12-verify-list.md)。** 手册里凡是标 ⚠️ 的数字，不可以直接报给客户。
2. **RM 数字只能来自发展商当期价目表。** 话术里的 `{...}` 位置由你现场填，手册不预设价格。
3. **政策会变。** 8% stamp duty、3% consent levy、Medini 豁免这三项在 2025–2026 年都动过，每季度重新核实一次。

## 数字标记规则

| 标记 | 含义 |
| --- | --- |
| ✅ | 发展商或官方渠道公布 |
| 📰 | 中介挂牌、媒体或第三方网站，方向可信但随时会变 |
| ⚠️ | 来源之间有冲突，或属于政策类，报价前必须核实 |
