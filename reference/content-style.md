# Content Style

How JB property content should sound and look across both tracks.

## Voice
- Clear, direct, helpful — not hype
- Lead with the buyer's question, then answer it
- Local and specific (name the area, the project, the number)

## Rules
- Pricing in public content: **"1.xx mil" format only** — never exact figures
- Always end with the [[contact-cta]] block
- Connectivity angle where relevant → link [[rts-timeline]]
